# Cutout

Minimal background remover with accounts, usage plans and paid subscriptions.
Upload an image, get a clean cutout, and export it as PNG, WebP or JPG at the
resolution your plan allows.

## Features

- Background removal powered by `rembg` and ONNX Runtime.
- Transparent PNG cutouts cached for re-export in other formats and sizes.
- Optional alpha matting, edge feathering and background compositing.
- Email/password accounts with opaque bearer tokens.
- Guest previews, free monthly quota, and Pro/Business subscriptions.
- Stripe Checkout, Billing Portal and webhook handling, with a development mode.
- Minimal light/dark interface built with React, Vite and Tailwind CSS.

## Stack

| Layer    | Technology                                      |
| -------- | ----------------------------------------------- |
| Backend  | FastAPI, Pydantic, Pillow, rembg, ONNX Runtime  |
| Storage  | SQLite (users, sessions, jobs) + filesystem     |
| Billing  | Stripe REST API via `httpx`                      |
| Frontend | React 18, Vite 5, TypeScript, Tailwind CSS      |

## Quick start

### Backend

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

The first removal downloads the selected model into the rembg cache. The API is
available at `http://localhost:8000`, with docs at `http://localhost:8000/api/docs`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`. Vite proxies `/api` to `http://127.0.0.1:8000`.

## Plans

| Plan     | Price              | Removals       | Max export |
| -------- | ------------------ | -------------- | ---------- |
| Guest    | Free               | 2 per day      | 1024 px    |
| Free     | Free               | 5 per month    | 1024 px    |
| Pro      | $9/mo or $90/yr    | 200 per month  | 4096 px    |
| Business | $29/mo or $290/yr  | 1,000 per month| 8192 px    |

Every plan supports PNG, WebP and JPG exports. Limits are defined in
`backend/plans.py`.

## Configuration

Copy `.env.example` to `.env` for reference, or export the variables in your
shell before starting the backend.

Key variables:

- `CUTOUT_DATA_DIR`: SQLite database location (default `backend/data`).
- `CUTOUT_CACHE_DIR`: transparent cutout cache (default `backend/data/jobs`).
- `GUEST_DAILY_LIMIT`: guest previews per day (default `2`).
- `PBKDF2_ITERATIONS`, `SESSION_DAYS`: account security/session lifetime.
- `CUTOUT_DEV_BILLING`: when `true`, upgrades apply instantly without Stripe.
- `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_PRICE_*`: live billing.
- `FRONTEND_ORIGINS`, `FRONTEND_URL`: CORS and billing redirect URLs.

For the frontend, set `VITE_API_URL` in `frontend/.env` only when the API is on a
different origin.

### Enabling Stripe

1. Create recurring prices for Pro and Business (monthly and yearly).
2. Set the four `STRIPE_PRICE_*` variables plus `STRIPE_SECRET_KEY`.
3. Set `CUTOUT_DEV_BILLING=false`.
4. Point a webhook at `POST /api/billing/webhook` for
   `checkout.session.completed` and `customer.subscription.*` events, then set
   `STRIPE_WEBHOOK_SECRET`.

## API overview

| Method | Path                        | Purpose                              |
| ------ | --------------------------- | ------------------------------------ |
| GET    | `/api/health`               | Runtime/model status                 |
| GET    | `/api/plans`                | Plan catalog and billing mode        |
| GET    | `/api/usage`                | Current quota for user or guest      |
| POST   | `/api/auth/signup`          | Create account                       |
| POST   | `/api/auth/login`           | Sign in                              |
| POST   | `/api/auth/logout`          | Revoke session                       |
| GET    | `/api/auth/me`              | Current user                         |
| POST   | `/api/remove`               | Remove background                    |
| POST   | `/api/jobs/{job_id}/export` | Re-export a cached cutout            |
| POST   | `/api/billing/checkout`     | Start subscription checkout          |
| POST   | `/api/billing/portal`       | Open Stripe billing portal           |
| POST   | `/api/billing/cancel`       | Cancel or downgrade                  |
| POST   | `/api/billing/webhook`      | Stripe webhook receiver              |

Authenticated requests use `Authorization: Bearer <token>`. Guest usage is
tracked with an `X-Client-Id` header generated by the frontend.

## Tests

```bash
cd backend
.venv/bin/python -m pytest -q

cd ../frontend
npm run build
```

The backend tests use a temporary data directory and a high guest limit set in
`backend/tests/conftest.py`, so they do not touch local usage data.

## Notes

- Cutouts are cached for `JOB_TTL_HOURS` and re-exporting does not consume quota.
- Uploads are limited to 25 MB and validated by content type and extension.
- For production, run the API behind HTTPS, serve `frontend/dist` from a static
  host or CDN, and keep the SQLite data directory on persistent storage.
